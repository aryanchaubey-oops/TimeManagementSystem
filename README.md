# Time Management System

A full-stack web application for task tracking, time management, and priority calculation.

## Tech Stack
- Java 21 & Spring Boot 3.2.0
- MySQL Database
- HTML, CSS, JavaScript (Fetch API)
- Maven

## How to Run
1. Configure MySQL in backend/src/main/resources/application.properties
2. Run TimeManagementApplication.java
3. Open http://localhost:8080/TIME TRACK/dashboard.html
